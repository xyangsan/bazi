- [ ] **节气计算** - 当前月柱计算不准确

- [ ] **年柱计算** - 需要以立春为界

- [ ] **自坐计算** - 完全未实现
  - 计算天干在地支中的状态
  
- [ ] **神煞计算** - 完全未实现
  - 需要计算多种神煞
  
- [ ] **起运年龄计算** - 当前使用随机数
  - 需要精确计算出生日到下一个节气的天数
